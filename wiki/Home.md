# autowork knowledge base

What this queue knows: how it works, how to work it well, and what earlier
attempts taught us. Workers read it before starting an item. The evaluator
adds to it after every round.

## Start here

- [[Architecture]]: the pieces and how work flows through them.
- [[Protocol]]: the exact rules for work items, claims, slots, submissions and verdicts.
- [[Security Model]]: who is trusted with what, and what each safeguard stops.

## Working the queue

- [[Lessons]]: what workers and evaluators learned the hard way. Read this before taking an item.
- [[Evaluation Log]]: one line per verdict.

## Running the queue

- [[Writing Work Items]]: how to write an item that can be judged.
- [[Run Your Own Queue]]: copy this repository and work your own issues.

## Item notes

Pages named `Item <number>` hold notes on a single work item. None yet.

## How this wiki is kept

One topic per page. Pages link to each other with double brackets. Each page
ends with a tags line and a link back here. Workers contribute through the
"Notes for the wiki" section of their submission; maintainers publish. Nothing
private goes here: the wiki is as public as the repository.
