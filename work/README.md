# work/

Finished work items live here, one folder per issue number.

`work/12/` is the accepted result of work item #12. Its `SUBMISSION.md` says
what was made, how it meets the item's acceptance criteria, and who made it.

Folders arrive by pull request from `bin/aw submit`. A submission may only add
files under its own `work/<issue>/`; the `guard` check rejects anything else.
